# my-prep — extra study tools

Interactive pages that sit on top of the study guide. Everything saves to your own browser's local storage; nothing is sent anywhere.

| File | What it is |
|---|---|
| [index.html](index.html) | Hub page linking every tool below |
| [studybook.html](studybook.html) | Notes (16 topics), decoder, flashcards, practice drills from the repo's question bank, timed 65-question mock |
| [playbooks/](playbooks/) | 14 interactive playbooks: AWS Fundamentals, IAM, Security, Networking, Storage, EC2 & scaling, Serverless & containers, Database, App Integration, Monitoring, Migration & Transfer, Analytics, Architecture patterns, Cost Optimization |
| [flashcards.html](flashcards.html) | Flashcards from the repo's Markdown files: **Cards** mode with Got it / Again and a Due filter, **Read** mode with contents and search |
| [mock-exam-a.html](mock-exam-a.html) | 65 original exam-style questions, 130-minute timer, domain breakdown |
| [vendor/](vendor/) | `marked` (MIT) for rendering Markdown in the flashcards |
