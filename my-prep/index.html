Sync across devices

Progress is always saved in this browser. Sync copies it to a JSON file in a GitHub repo so your laptop, phone and Claude all see the same data. Newest change per item wins.

  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → this repo (or a private one just for progress).
  3. Permissions → Repository → Contents: Read and write. Nothing else. Expiry: a month or two.
  4. Paste it below on each device and press Save & sync. The token stays in this browser only.

Your repo is public, so progress.json is public too (scores and notes, nothing secret). Use a private repo in "Repo" if you prefer; tell Claude its name.
